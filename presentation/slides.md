# Problem

### Context
- **Product teams** have deep knowledge of the features they build.
- **Support team** understands the product broadly, but not every implementation detail.
- **Customer teams** integrate the product for specific clients.

### Challenge
- A customer team opens an issue, but the root cause is unclear.
- Is it a **bug**, **configuration issue**, or **known limitation**?
- If it is a bug, **which product team owns it**?
- Support spends time searching documentation, old issues, and similar cases.

### Core problem

**Customer Team → Support → ? → Product Team**

`? = Bug / Configuration / Known Issue / Ownership`
