- (constraint) Existing reality: SuppBro is Python 3.11 with Makefile/requirements.txt; current POCs live in scripts/hw4-hw7 and cover RAG, external tools, deterministic workflow, LangGraph graph, and Streamlit trace UI.
- (direction) Fast path selected; only deliverable requested is ARCHITECTURE-SPINE.md for BMAD quick-dev build substrate.
- (assumption) Target source seed uses src/supp_bro with config, domain, retrieval, tools, workflows, and ui packages; tests/unit is the default quick-dev test home.
- (decision) AD-1: Use layered ports-and-adapters around a domain workflow state; binds all product package code and prevents UI, graph nodes, retrieval, and external tools from owning incompatible state or calling each other directly.
- (decision) AD-2: Domain owns routes, contracts, and state schemas; adapters translate provider-specific payloads into domain contracts before workflow/UI use; prevents duplicated Literal route sets and provider JSON leakage.
- (decision) AD-3: Workflows orchestrate deterministic state transitions and call retrieval/tools through contracts; graph nodes mutate only the shared workflow state and append trace observations; prevents hidden side effects and untraceable routing.
- (decision) AD-4: UI is an adapter over workflow input/output state; Streamlit may render chat, plan, RAG, tools, and state JSON but must not classify, retrieve, call external APIs, or compose final answers; prevents demo UI drift from product behavior.
- (decision) AD-5: Config centralizes environment access and secrets; downstream modules receive settings or tokens through typed inputs and never print or persist MONGODB_URI; prevents scattered env reads and secret leakage.
- (version) Verified current fit on 2026-08-23: Python 3.11 docs current at 3.11.15; LangGraph docs describe StateGraph as stateful graph runtime and reference v1.2.9 API; Streamlit latest release notes show 1.61.0.
- (decision) Reviewer fix AD-6: domain.state.WorkflowState is the canonical workflow state and TraceView/state projections are the UI boundary; prevents incompatible state/trace shapes.
- (decision) Reviewer fix AD-7: routes and adapter ports define required plan shapes, domain request contracts, and evidence observation contracts; prevents route semantic drift and adapter-specific workflow calls.
- (decision) Reviewer fix AD-8: provider availability is capability-scoped and missing credentials/timeouts/rate limits become typed observations; prevents local quick-dev startup failures and inconsistent degraded mode.
- (decision) Reviewer fix AD-9: first src/supp_bro slice establishes import/install contract and product modules cannot rely on homework-style sys.path mutation.
